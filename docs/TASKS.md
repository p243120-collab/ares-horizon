## T04: Verify every number and cite real sources

Why: Credibility. The challenge asks for real trade-offs, so each value needs a source or an honest ASSUMPTION label.

Steps:
1. Open docs/SOURCES.md. For each row marked TODO, find the real NASA (or other agency) page or paper.
2. Search for: NASA Baseline Values and Assumptions Document (BVAD); NASA Mars fact sheet; NASA Moon fact sheet; Curiosity RAD dose; Kilopower project.
3. Put the real URL in the Source column and set Status to verified, or to ASSUMPTION with a reason.
4. If a verified value differs from the code, update src/engine/constants.ts or scenarios.ts, then re-run tests and re-balance (see T05). Never invent a link.

Done when:
- docs/SOURCES.md contains no TODO
- verify shows no FAIL

## T05: Playtest and balance the game

Why: A game that is too easy or impossible teaches nothing. Evidence from real players is what a supervisor trusts.

Steps:
1. Get at least 5 different people to play a full mission without help. Observe silently.
2. Log each session in docs/PLAYTEST.md (no names).
3. Fix the top three confusions (copy, controls, hints). Retune scenario numbers if needed.
4. Keep tests/engine/balance.test.ts passing: competent wins, idle loses crew, sabotage always fails.
5. Fill the Summary section of docs/PLAYTEST.md with what changed and why.

Done when:
- docs/PLAYTEST.md has at least 5 session rows
- verify shows no FAIL

Finish with: `python scripts/ares_setup.py done T05`
